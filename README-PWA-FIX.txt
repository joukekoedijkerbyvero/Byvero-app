byVERO PWA fix

Upload/replace ALL files in your GitHub Pages repository root.
Important: icon-192.png, icon-512.png and icon-maskable-512.png must be present.

After GitHub Pages redeploys:
1. Remove the old byVERO shortcut from your phone.
2. In Chrome, open the published byVERO URL.
3. Refresh once or close/reopen Chrome.
4. Open Chrome menu. You should now see 'Install app' / 'App installeren'
   rather than only 'Add to Home screen'.
5. Install byVERO.

If Chrome still uses the old cached version, clear site data for the byVERO GitHub Pages URL and reload.
