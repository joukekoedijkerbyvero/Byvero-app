# byVERO v0.1 Build 2

Deze build bevat:
- Volledige 8-staps onboarding
- Nederlands / Engels
- Lokale opslag van antwoorden
- Indicatieve aankoopbudgetberekening
- Eerste uitlegbare Location Match
- Top 3 locaties met Lifestyle / Property / Budget / Practical scores
- Accountscherm (lokaal prototype)
- Dashboard met Location Match, budget en My Homes teaser
- PWA-configuratie

## Publiceren
Vervang in je bestaande GitHub Pages repository alle bestanden door de bestanden uit deze ZIP.
Verwijder oude versies waar nodig, commit changes, en laad de site daarna opnieuw.
Bij cachingproblemen: Chrome > sitegegevens wissen voor de GitHub Pages-site en opnieuw openen.

Let op: dit is nog een prototype zonder echte serverdatabase of echte authenticatie.
