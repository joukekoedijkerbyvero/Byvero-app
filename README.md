# byVERO v0.1 prototype

First working PWA prototype for byVERO.

Included:
- Mobile-first welcome screen
- NL / EN language switching
- Onboarding question 1
- Immediate value feedback after an answer
- Local persistence of language and answer
- PWA manifest + service worker foundation

## Run locally

From this folder:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
